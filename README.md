# Heart Animation

Pequena animação gráfica em Python que desenha um coração vermelho utilizando curvas matemáticas e o módulo Turtle.

## Conceitos praticados

- funções matemáticas;
- seno e cosseno;
- coordenadas cartesianas;
- desenho iterativo;
- biblioteca gráfica Turtle.

## Executando

~~~bash
git clone https://github.com/it0l/Heart.git
cd Heart
python heart.py
~~~

O módulo Turtle faz parte da biblioteca padrão do Python, mas requer um ambiente com interface gráfica.
